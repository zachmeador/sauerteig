# Terrain materials

Eight stable material slots: concrete, gunmetal, rust, worn concrete, hazard paint,
amber light, rock, and earth. Slots 0–5 retain their meaning in existing maps.

The six photographic surfaces come from [Poly Haven](https://polyhaven.com).
Their [asset license is CC0 1.0](https://polyhaven.com/license), permitting modified
redistribution. `manifest.json` records the original asset pages, authors, pinned
source downloads and checksums, preparation changes, and cooked file hashes.
Hazard paint is authored paint over the CC0 metal-plate detail. Amber light is an
authored constant texture. The authored utility texture pixels are also dedicated
to [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/); project source code
remains MIT.

Each slot contains two 512 × 512 PNGs:

- `albedo.png`: RGB is sRGB base color, alpha is linear ambient occlusion.
- `normal_roughness.png`: RGB is a linear OpenGL tangent-space normal, alpha is
  linear roughness. The client must renormalize sampled normals.

Metallic is a per-material scalar approximation, not a source per-pixel map.
These opaque surfaces do not use alpha transparency. Texture tiling is expressed
in world metres in the manifest; these are chosen game scales. Runtime mipmaps
are generated by the client. The eight pairs use 21.33 MiB of uncompressed RGBA8
GPU storage including every mip level, excluding prop textures.

The normal build consumes checked-in cooked PNGs. To reproduce them, install
Pillow and run `python3 scripts/cook-materials.py --download`. The checked-in
textures were cooked with Pillow 11.3.0 and JPEG codec 8.0; different decoder
versions can change output pixels and hashes. Downloads are pinned
and checksum-checked; source files are cached under ignored `.local/material-sources`.
Subsequent runs can omit `--download` and work offline. The cooker identifies
itself to Poly Haven and prints source credit. The game makes no live catalog or
download API calls.
